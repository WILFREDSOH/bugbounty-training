# Bug Bounty Training

Journal d'entraînement à la sécurité web, en préparation du Bug Bounty étudiant
UYBHYS 2026 (Unlock Your Brain Harden Your System), Le Quartz, Brest.

Étudiant ingénieur à l'ENIB, spécialisation cybersécurité.

## Contenu

Notes méthodologiques par classe de vulnérabilité, construites en résolvant les
labs de la PortSwigger Web Security Academy. Chaque entrée décrit la faille, la
méthode de découverte, l'exploitation, l'impact et la correction.

- `IDOR.md` — Contrôle d'accès cassé et IDOR
- `Auth.md` — Authentification
- `XSS.md` — Cross-site scripting
- `SQLi.md` — Injection SQL
- `Recon.md` — Reconnaissance (nmap, ffuf, analyse JavaScript)
- `modele-rapport.md` — Modèle de rapport de vulnérabilité

## Outils

Burp Suite, nmap, ffuf, SecLists.

## Avertissement

Contenu uniquement pédagogique, réalisé sur des environnements d'entraînement
autorisés (PortSwigger Web Security Academy, OWASP Juice Shop). Ne jamais tester
un système sans autorisation écrite.
